Django URL Shortener API

A simple URL shortening RESTful API built using Django and Django REST Framework as part of the Innovaxel ASE Take-Home Assignment.

---

Features

- Shorten long URLs
- Retrieve original URLs using short codes
- Update shortened links
- Delete shortened links
- Get stats (access count, timestamps)
- Simple frontend using HTML + JavaScript
- RESTful API with JSON responses

---

Tech Stack

- Python 3.11+
- Django
- Django REST Framework
- shortuuid (for generating unique short codes)
- HTML + JavaScript (for frontend)
